# Переводы (RU | EN)

Весь видимый текст лежит в словарях `src/i18n/<язык>/`, в коде — только ключи. Переключатель **RU | EN** стоит рядом с кружками тем;
язык меняется на лету (без перезагрузки и без потери состояния), запоминается в `localStorage` (`nnlab-lang`), а при первом заходе
берётся из языка браузера (русский → RU, иначе EN). `?lang=ru|en` в адресе перекрывает сохранённый выбор.
Формат файлов `nn3d-space v1` и его JSON-ключи от языка не зависят: файл, сохранённый в RU, открывается в EN и наоборот.

## Как устроено

| Что | Где |
|---|---|
| Механизм (`t`, `L`, `scope`, форматы чисел, смена языка) | `src/i18n/i18n.js` |
| Интерфейс: шапка, каталог, диалоги, «Мои», конструктор | `ru/ui.js`, `ru/lab.js` |
| Лаборатории (сетка, поверхность, облака точек), слои, обучение | `ru/labs.js`, `ru/stack.js`, `ru/train.js`, `ru/models.js` |
| Текстовая лаборатория (слова, ячейки, внимание) | `ru/tokens.js` |
| Конструктор графа блоков | `ru/graph.js`: `graph.*` — интерфейс, `blk.*` — блоки |
| Тексты одного пространства | `ru/spaces/<id>.js` → ключи `sp.<id>.*` |
| Список файлов | `ru/index.js` (генерируется, см. ниже) |

В `en/` — те же файлы с теми же ключами. Проверка `node tools/check-spaces.mjs` (и `tools/check-spaces.html` в браузере) падает,
если ключ есть только в одном из языков.

## Как пользоваться в коде

```js
import { t, L, scope, fmtNum, num } from '../src/i18n/i18n.js';

t('graph.epoch', { e: 3, n: 40 });        // строка на текущем языке: «Эпоха 3 из 40» / «Epoch 3 of 40»
L('graph.epoch', { e: 3, n: 40 });        // «ленивый» текст для конфигов: переводится при показе и при смене языка
const S = scope('sp.perceptron');         // тексты пространства: S('title') → L, S.t('k', p) → строка, S.h('k', p) → HTML
```

- `{имя}` в значении подставляется из параметров. Числа форматируются по языку (`0,5` / `0.5`); `num(x, 2)` — с фиксированным числом знаков.
- Множественное число: значение-объект `{ one, few, many, other }` и параметр `n` (`Intl.PluralRules`). В английском достаточно `one` и `other`.
  Ключи объекта не должны называться `one/few/many/other/zero/two` — такой объект считается набором форм.
- Ключ, оканчивающийся на `Html`, содержит разметку (доверенную, из словаря); подстановки в неё экранируются.
  Всё остальное экранируется целиком. Текст из загруженных файлов в `innerHTML` не вставляется — только `textContent` или экранированный текст.
- В 3D-подписях числа остаются в виде `+1.00` (`formatValue`), в панелях — `fmtNum` / `fmtSigned`.
- Элементы в HTML-шаблонах: `T('key')` → `<span data-t>`, атрибуты — `At('title', 'key')`; при смене языка они переводятся сами (`relabel`).
  Динамические элементы: `setT(el, L('key', p))`; готовая строка (текст пользователя) — `setText`.
- Данные пользователя (названия, имена файлов и столбцов, классы картинок) не переводятся.

## Как добавить новую строку

1. Придумайте ключ в нужной области (`graph.myButton`, `sp.perceptron.newHint`).
2. Добавьте его в **оба** словаря: `src/i18n/ru/<область>.js` и `src/i18n/en/<область>.js`.
3. В коде используйте `t('ключ')`, `L('ключ')` или `T('ключ')`. Строк прямо в коде быть не должно.
4. Проверьте: `node tools/check-spaces.mjs` и страница на обоих языках.

## Как добавить новое пространство

Тексты пространства — в `src/i18n/ru/spaces/<id>.js` и `src/i18n/en/spaces/<id>.js` (объект с ключами `title`, `summary`, `uses`, …).
В конфиге `spaces/<id>.js`: `const S = scope('sp.<id>')`, затем `title: S('title')`, `summary: S('summary')` и т. д.
Теги — латинские id (`tag.<id>` в `ui.js`); подписи, которые должны переводиться, — `S('…')` (L-объекты), а не строки.
Затем впишите файл в `ru/index.js` и `en/index.js`: `import sp_my from './spaces/my.js'` и строка `'my': sp_my` в объекте `sp`.

## Как добавить блок конструктора

Файл `src/engine/blocks/<id>.js`: `title: L('blk.<id>.title')`, `info`, подписи портов и параметров — тоже `L(...)`; тексты блока — в `graph.js`
обоих языков в разделе `blk.<id>`. Ошибки — `throw fail('ключ', { параметры })` (`src/engine/graph/fail.js`), числа в результатах —
`numL(x)` или параметры `L(...)`, чтобы они пересчитывались при смене языка.

## Как добавить новый язык (например, `kk`)

1. Скопируйте папку `src/i18n/ru/` в `src/i18n/kk/` и переведите значения (ключи не менять).
2. В `src/i18n/i18n.js` добавьте `'kk'` в `LANGS` (кнопка переключателя появится сама), в `locale()` — код локали (`kk-KZ`),
   в `detectLang()` — правило выбора по языку браузера.
3. Добавьте подпись языка `common.lang.kk` в `ui.js` всех языков.
4. Правила текстовых лабораторий для нового языка — `txt.*` в `models.js` (окончания и основы слов) и слова моделей `w.*` в словарях `lstm`, `sentiment`, `next-word`, `word2vec`.
5. Для языка с другими формами множественного числа задайте нужные категории (`one`, `few`, `many`, `other` …) там, где используются формы.
6. `node tools/check-spaces.mjs` сверяет наборы ключей всех языков из `LANGS`.
