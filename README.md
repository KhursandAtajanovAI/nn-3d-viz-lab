# nn-3d-viz-lab

Лаборатория 3D-визуализации нейронных сетей в браузере на [Three.js](https://threejs.org/).
Без сборки и зависимостей: Three.js подключается через import map с CDN.

**Демо:** https://khursandatajanovai.github.io/nn-3d-viz-lab/

## Возможности

- Нейросеть отображается как слои из нейронов-сфер, соединённых линиями-связями.
- Единая палитра: тёплый (оранжевый) — положительное значение/вес, холодный (синий) —
  отрицательное, серый — слабое. Насыщенность линии = величина |w|.
- Свечение (bloom): чем сильнее активирован нейрон, тем ярче он светится.
  Связи в покое тонкие и приглушённые, при прохождении сигнала — толстые и яркие.
- Вращение, масштаб и сдвиг сцены мышью (OrbitControls).
- Анимация forward-pass: слой за слоем загораются нейроны, по связям бегут импульсы.
- Боковая панель на русском: описание архитектуры, пояснение обозначений,
  объяснение forward-pass с текущим этапом, итог на выходном слое простыми словами.
- Наведение на нейрон — слой, номер, активация, взвешенная сумма z, входящие/исходящие связи
  с весами и вкладами. Наведение на связь — какие нейроны она соединяет, точный вес и вклад w·x.
- Режимы «Визуальный» / «Детальный · числа» (кнопка или клавиша N): в детальном режиме
  у каждого нейрона видно значение активации (обновляется синхронно с анимацией),
  а у связей наведённого нейрона — значения весов.
- Настраиваемая архитектура (например, `4, 6, 6, 3`; большие слои раскладываются сеткой),
  функция активации (tanh / ReLU / sigmoid), скорость анимации, перегенерация весов.

## Запуск локально

Нужен любой статический HTTP-сервер (ES-модули не грузятся через `file://`):

```bash
python -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000/.

## Структура

```
index.html                      — основная страница лаборатории
src/main.js                     — сцена, bloom, OrbitControls, наведение, UI
src/network.js                  — модель сети: веса (Xavier) и forward-pass
src/NetworkView.js              — 3D-представление: нейроны, связи, импульсы, подписи
src/ForwardPassAnimation.js     — пошаговая анимация forward-pass
src/panels.js                   — содержимое карточек боковой панели
src/palette.js                  — единая цветовая палитра
src/format.js                   — форматирование чисел и русские подписи
src/styles.css                  — стили интерфейса
examples/simple-demo/           — минимальный пример 3 → 4 → 2 (проверка связки)
.github/workflows/pages.yml     — автодеплой на GitHub Pages
```
