# nn-3d-viz-lab

Интерактивная лаборатория для изучения нейронных сетей в 3D на [Three.js](https://threejs.org/).
Без сборки и зависимостей: Three.js подключается через import map с CDN.

**Сайт:** https://khursandatajanovai.github.io/nn-3d-viz-lab/

## Как устроено

- **Каталог** (`index.html`) — главная страница со списком «пространств», поиском и фильтром по категориям.
- **Пространство** — отдельная демонстрация (конкретная сеть или задача) со своей 3D-сценой и объяснениями.
  Открывается как `space.html?id=<id>`.
- **Движок** (`src/engine/`) — общий для всех пространств: 3D-сцена со свечением, нейроны и связи,
  анимация forward-pass, боковая панель, наведение на нейроны/связи, режим с числами.
- **Конфиги пространств** (`spaces/<id>.js`) — только данные: архитектура, веса или seed, входы,
  тексты. Новый файл в `spaces/` автоматически появляется в каталоге после деплоя —
  см. [spaces/README.md](spaces/README.md).

## Пространства

| Категория | Пространство | Файл |
|---|---|---|
| Основы | Простая сеть 3 → 4 → 2 | `spaces/simple-mlp.js` |
| Основы | XOR: задача, которую не решить одним нейроном | `spaces/xor.js` |
| Основы | Конструктор полносвязной сети | `spaces/playground.js` |

## Возможности движка

- Единая палитра: тёплый (оранжевый) — положительное значение/вес, холодный (синий) — отрицательное,
  серый — слабое. Свечение (bloom) растёт с активацией; связи в покое тонкие, при прохождении сигнала — яркие.
- Вращение, масштаб и сдвиг сцены мышью (OrbitControls); пробел — forward pass, N — числа.
- Боковая панель на русском: описание сцены, «Под курсором» (активация, взвешенная сумма, веса и вклады),
  итог на выходе простыми словами, объяснение forward-pass с текущим этапом, легенда.
- Режимы «Визуальный» / «Детальный · числа» без перезагрузки страницы.

## Запуск локально

```bash
bash tools/build-manifest.sh      # собрать spaces/manifest.json
python -m http.server 8000        # или: npx serve .
```

Откройте http://localhost:8000/. Проверка конфигов пространств: `node tools/check-spaces.mjs`.

## Структура

```
index.html                  — каталог пространств
space.html                  — универсальная страница пространства (?id=…)
spaces/                     — конфиги пространств (один файл = одно пространство)
  manifest.json             — список пространств (генерируется tools/build-manifest.sh)
  _template.js, README.md   — шаблон и инструкция
src/engine/                 — общий движок
  boot.js                   — загрузка конфига и выбор визуализатора по type
  SceneKit.js               — сцена: рендер, bloom, HTML-подписи, камера, цикл
  NetworkLab.js             — визуализатор полносвязной сети: панель + сцена + анимация
  NetworkView.js            — 3D-представление: нейроны, связи, импульсы, подписи
  ForwardPassAnimation.js   — пошаговая анимация forward-pass
  panels.js, sidebar.js     — содержимое боковой панели
  models/mlp.js             — модель полносвязной сети (без зависимости от Three.js)
  catalog.js                — категории каталога
  palette.js, format.js     — палитра, форматирование и русские подписи
  base.css, lab.css         — стили
src/hub/                    — каталог (hub.js, hub.css)
tools/                      — build-manifest.sh, check-spaces.mjs
examples/simple-demo/       — минимальный технический тест Three.js без движка
.github/workflows/pages.yml — сборка манифеста, проверка пространств и деплой на GitHub Pages
```
