# nn-3d-viz-lab

Интерактивная лаборатория для изучения нейронных сетей в 3D на [Three.js](https://threejs.org/).
Без сборки и зависимостей: Three.js подключается через import map с CDN.

**Сайт:** https://khursandatajanovai.github.io/nn-3d-viz-lab/

## Как устроено

- **Каталог** (`index.html`) — все пространства с поиском, фильтрами по категории, тегу, уровню и типу вычислений.
  Фильтры сохраняются в адресе страницы, поэтому ссылкой на подборку можно поделиться.
- **Пространство** — отдельная демонстрация со своей 3D-сценой и объяснениями на русском: `space.html?id=<id>`.
- **Движок** (`src/engine/`) — общий для всех пространств: сцена со свечением, панель слева, наведение, режим «с числами».
- **Конфиги** (`spaces/<id>.js`) — только данные и модель. Новый файл автоматически появляется в каталоге после деплоя —
  см. [spaces/README.md](spaces/README.md).

Бейдж на каждой карточке честно говорит, насколько «настоящие» числа:
**Реальные вычисления** (всё считается по показанным весам и формулам), **Обучается в браузере** (сеть обучается при открытии
страницы на синтетических данных) или **Упрощённая иллюстрация** (архитектура точная, ответы демонстрационные).

## Пространства (32)

| Категория | Пространства |
|---|---|
| Основы | Перцептрон · Простая сеть 3 → 4 → 2 · XOR · Конструктор полносвязной сети |
| Изображения | MNIST (можно рисовать цифру) · Fashion-MNIST · CIFAR-10 · ImageNet и ResNet-50 |
| Текст (NLP) | Анализ тональности · Автодополнение и внимание · RNN/LSTM · Word2Vec |
| Другие задачи | Регрессия цены · Автоэнкодер · Рекомендации · Кластеризация (карта Кохонена) |
| Обучение | Градиентный спуск · Backpropagation · Обучение по эпохам с графиком loss · Q-learning |
| Библиотека моделей | LeNet-5 · AlexNet · VGG-16 · ResNet · MobileNet · U-Net · GAN · VAE · DQN · Transformer · GPT · BERT |

## Визуализаторы движка

| `type` | Файл | Для чего |
|---|---|---|
| `mlp` | `NetworkLab.js` | Полносвязные сети: нейроны, веса, forward pass |
| `stack` | `StackLab.js` | Архитектуры из блоков: свёртки с настоящими картами признаков, skip-связи, энкодер/декодер |
| `tokens` | `TokensLab.js` | Текст: эмбеддинги, мешок слов, LSTM-ячейки, внимание |
| `scatter` | `ScatterLab.js` | Облака точек: эмбеддинги, рекомендации, кластеризация |
| `surface` | `SurfaceLab.js` | Поверхность ошибки и оптимизаторы (SGD, момент, Adam) |
| `train` | `TrainLab.js` | Обучение: пошаговый backprop и эпохи с графиками |
| `gridworld` | `GridLab.js` | Обучение с подкреплением (Q-learning) |

Общие части: `SceneKit.js` (рендер, bloom, подписи, камера), `BaseLab.js` (панель, наведение, подсказки), `Timeline.js`,
`chart.js` (SVG-графики), `three-utils.js`. Модели без Three.js — в `src/engine/models/` (MLP с backprop, свёртки, генераторы
синтетических картинок, оптимизаторы, наборы данных).

## Запуск локально

```bash
bash tools/build-manifest.sh      # собрать spaces/manifest.json
node tools/check-spaces.mjs       # проверить все конфиги (Node 18+)
python -m http.server 8000        # или: npx serve .
```

Откройте http://localhost:8000/.

## Деплой

`.github/workflows/pages.yml` при каждом push в `main` собирает манифест, проверяет все пространства
(импорт, обязательные поля, прогон логики) и только потом публикует сайт на GitHub Pages.
