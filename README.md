# nn-3d-viz-lab

Лаборатория 3D-визуализации нейронных сетей в браузере на [Three.js](https://threejs.org/).
Без сборки и зависимостей: Three.js подключается через import map с CDN.

## Возможности (MVP)

- Нейросеть отображается как слои из нейронов-сфер, соединённых линиями-связями.
  Цвет линии — знак веса (красный > 0, синий < 0), яркость — величина |w|.
- Вращение, масштаб и сдвиг сцены мышью (OrbitControls).
- Анимация forward-pass: слой за слоем загораются нейроны (яркость = |активация|),
  по связям бегут импульсы. В конце показывается вход и выход сети.
- Настраиваемая архитектура (например, `4, 6, 6, 3`; большие слои раскладываются сеткой),
  функция активации (tanh / ReLU / sigmoid), скорость анимации, перегенерация весов.

## Запуск локально

Нужен любой статический HTTP-сервер (ES-модули не грузятся через `file://`):

```bash
python -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000/.

## Структура

```
index.html                      — основная страница лаборатории
src/main.js                     — сцена, камера, OrbitControls, UI
src/network.js                  — модель сети: веса (Xavier) и forward-pass
src/NetworkView.js              — 3D-представление: нейроны, связи, импульсы
src/ForwardPassAnimation.js     — пошаговая анимация forward-pass
src/styles.css                  — стили интерфейса
examples/simple-demo/           — минимальный пример 3 → 4 → 2 (проверка связки)
.github/workflows/pages.yml     — автодеплой на GitHub Pages
```
